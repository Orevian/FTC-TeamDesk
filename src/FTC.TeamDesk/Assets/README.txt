Place your application icon here as:  icon.ico

When src/FTC.TeamDesk/Assets/icon.ico exists, the build automatically uses it as
  - the icon of FTC.TeamDesk.exe (ApplicationIcon),
  - the window / taskbar icon,
  - the small icon in the custom title bar.
If the file is missing the app still builds and runs (without a custom icon).
Tip: use a multi-size .ico (16, 24, 32, 48, 64, 256 px) so it stays sharp at every DPI.
